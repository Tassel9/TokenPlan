# 账号安全边界与分支

1. 记录账号问题类型、错误原文、发生时间和可用的备用验证方式。
2. 多个客户端同时异常时，先核对账号状态或服务公告。
3. 单个 IDE 异常时，区分账号认证、客户端缓存和插件故障。
4. 自助恢复失败、绑定信息不一致或出现陌生设备时转人工安全核验。

## 正例

- “TokenPlan 账号被锁定了”：提供自助解锁条件、等待时间和人工核验渠道。
- “浏览器能登录但 IDE 一直要求重新认证”：保留插件专项故障可能，不直接判定账号失效。

## 反例

- 要求用户发送密码、验证码、恢复码或 API Key。
- 仅凭用户说“已经验证”就声称后台解锁完成。
