# 退款诉求边界与示例

| 类型 | 可回答范围 | 必须停止的边界 |
|---|---|---|
| 公开规则 | 条件、材料、公开时限、例外 | 不判断某个用户是否满足资格 |
| 个人资格 | 说明公开审核条件 | 没有业务记录时不下资格结论 |
| 提交退款 | 说明公开申请入口和材料 | 没有写 Tool 时不声称已经提交 |
| 退款进度 | 说明公开处理阶段 | 没有状态 Tool 时不推测进度或到账日期 |

## 正例

- “购买后多久内可以申请退款？”：检索对应渠道、套餐、地区和生效版本。
- “退款通常需要什么材料？”：回答公开材料并保留审核边界。

## 反例

- “我的订单肯定能退吗？”：这是个人资格核验，不能只凭公开政策确认。
- “帮我退掉”或“退款到哪了？”：需要真实业务 Tool；工具缺失时转人工。
