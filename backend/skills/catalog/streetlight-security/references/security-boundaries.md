# 智慧路灯终端接入安全边界与分支

1. 记录智慧路灯编号、单灯控制器编号、错误原文、发生时间和网络状态。
2. 多盏路灯终端同时异常时，先核对网关、网络链路和平台服务状态。
3. 单盏路灯终端异常时，区分路灯供电、通信模块、证书和绑定关系。
4. 自助恢复失败、绑定信息不一致或出现未知路灯终端时转人工安全核验。

## 正例

- “智慧路灯 L-102 认证失败”：提供供电、网络、时间同步、证书和绑定关系的核验顺序。
- “同一路灯网关下只有一盏灯离线”：保留路灯供电或通信模块故障可能，不直接判定平台异常。

## 反例

- 要求用户发送完整私钥、设备证书或接入令牌。
- 仅凭用户说“已经重连”就声称平台认证已经恢复。
