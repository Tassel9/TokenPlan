# 工单撤回诉求边界与示例

| 类型 | 可回答范围 | 必须停止的边界 |
|---|---|---|
| 公开规则 | 条件、必填信息、公开时限、例外 | 不判断某张工单是否可撤回 |
| 操作资格 | 说明公开审批条件 | 没有业务记录时不下资格结论 |
| 提交撤回 | 说明操作入口和必填信息 | 没有写 Tool 时不声称已经提交 |
| 撤回进度 | 说明公开处理阶段 | 没有状态 Tool 时不推测进度或完成时间 |

## 正例

- “工单派发后多久内可以撤回？”：检索对应工单阶段、区域和生效版本。
- “退回工单需要提供哪些信息？”：回答公开要求并保留审批边界。

## 反例

- “WO-208 肯定能撤回吗？”：这是具体工单资格核验，不能只凭公开规则确认。
- “帮我撤回”或“退回到哪一步了？”：需要真实业务 Tool；工具缺失时转人工。
